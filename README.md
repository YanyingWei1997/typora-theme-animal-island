# Animal Island · Typora Theme

> A cozy Animal Crossing–inspired theme for Typora — warm parchment, mint accents, soft 3D pillow shadows.

一款灵感来自《集合啦！动物森友会》和 [animal-island-ui](https://github.com/guokaigdg/animal-island-ui) 的 Typora 主题，包含**日间**和**夜间**两个版本。

---

## ✨ 特色

- 🥛 **温和的奶油纸面**：低饱和暖白底色，长时间写作不刺眼
- 🌿 **薄荷绿点缀**：链接、强调、表头、代码标记统一使用薄荷色，配色克制不杂乱
- 🎴 **6 级标题各有特色**，层级一眼可辨：
  - **H1**：居中三色胶囊勋章
  - **H2**：渐变背景卡片便签 + 左厚竖块
  - **H3**：左竖线 + 底部虚线封闭
  - **H4**：薄荷文字 + 短"记号笔"下划线
  - **H5**：米色椭圆胶囊贴纸
  - **H6**：大写微标签
- 🐾 **小动物脚印分隔线**：`---` 渲染为薄荷色脚印
- 💊 **3D 软枕阴影**：引用块、代码块、输入框模拟拟物按键的下压感
- 🌙 **深森林夜间版**：发光薄荷胶囊 + 深色木板背景
- 📝 **修复 Typora 源代码模式的对比度**：默认蓝色 markdown 标记被替换为主题色，行号清晰可读

## 🚀 安装

1. 打开 Typora
2. 菜单：**文件（File） → 偏好设置（Preferences） → 外观（Appearance） → 打开主题文件夹（Open Theme Folder）**
3. 把 `animal-island.css` 和 `animal-island-dark.css` 复制到该文件夹
4. 重启 Typora
5. 在菜单栏 **主题（Themes）** 中选择：
   - **Animal Island** — 日间版
   - **Animal Island Dark** — 夜间版

> 💡 修改 CSS 后无需重启，只需在主题菜单切到任意其它主题再切回即可热更新。
